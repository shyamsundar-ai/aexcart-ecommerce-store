# AexCart – E-commerce Store (Internship Demo)

A responsive front-end e-commerce store made with HTML, CSS and JavaScript.

## Features
- Responsive layout for mobile and desktop
- Product cards with category labels and prices
- Search products by name
- Filter products by category
- Add items to cart and change quantities
- Automatic subtotal and cart item count
- Cart data saved in browser localStorage
- Demo checkout message (no real payment processing)

## Run the project
1. Download and extract `shyam-ecommerce-store.zip`.
2. Open the extracted folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.
4. Try searching, filtering, adding products and changing cart quantities.

No installation or backend is required.

## GitHub upload
1. Sign in to GitHub and create a new repository named `aexcart-ecommerce-store`.
2. Keep it Public if your internship reviewer needs to view it; do not upload passwords, API keys or personal data.
3. On the repository page choose **Add file → Upload files**.
4. Extract this ZIP first, then upload the files inside the project folder (not the ZIP alone).
5. Add a commit message such as `Add AexCart e-commerce store` and click **Commit changes**.
6. Open the repository and copy its URL.

## Internship submission
Submit the GitHub repository URL if the internship asks for a source-code link. If it asks for a ZIP, submit the original ZIP file. If it asks for a report, include:
- Project title: AexCart – E-commerce Store
- Technologies: HTML, CSS, JavaScript
- Objective: Build a responsive online store interface.
- Modules: Product listing, search/filter, shopping cart, quantity update, subtotal and demo checkout.
- Testing: Verify search, category filters, cart quantity, subtotal and mobile layout.
- Limitation: This is a front-end demonstration; it does not include a real database, user authentication, server or payment gateway.
